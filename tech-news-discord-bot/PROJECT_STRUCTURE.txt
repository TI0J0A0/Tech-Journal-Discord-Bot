FLUXO DE EXECUÇÃO:
═══════════════════════════════════════════════════════════════════════════════

1. INICIALIZAÇÃO (Startup)
   └─ TechNewsDiscordBotApplication.main()
      └─ SpringApplication.run()
         └─ @SpringBootApplication
            └─ @EnableScheduling
               └─ DiscordBotConfig.jda()
                  └─ JDABuilder.createDefault().awaitReady()
                     └─ "Discord Bot connected!"

2. AGENDAMENTO (Background)
   └─ FeedScheduledTask
      └─ @Scheduled (fixedDelay = 3600000ms)
         └─ Executar a cada 1 hora (configurável)

3. CICLO DE EXECUÇÃO (A cada N horas)
   └─ FeedScheduledTask.fetchAndPublishNews()
      └─ NewsService.fetchAndPublishNews()
         ├─ RssFeedService.fetchFeeds()
         │  ├─ Para cada URL em FeedProperties.urls
         │  │  └─ Parse XML/Atom com ROME
         │  └─ Retorna List<FeedItem>
         │
         ├─ Para cada FeedItem:
         │  ├─ SentNewsRepository.existsByLink()
         │  │  └─ Checar se já foi enviado
         │  │
         │  ├─ Se não enviado:
         │  │  ├─ DiscordMessageService.sendNewsToDiscord()
         │  │  │  ├─ EmbedBuilder.build()
         │  │  │  └─ TextChannel.sendMessageEmbeds().queue()
         │  │  │
         │  │  └─ SentNewsRepository.save()
         │  │     └─ Persiste em H2
         │  │
         │  └─ Se já enviado:
         │     └─ Log.debug("Skipping duplicate")

4. CICLO CONTÍNUO
   └─ Próxima execução agendada...

ARQUIVOS DE CONFIGURAÇÃO A EDITAR:
═══════════════════════════════════════════════════════════════════════════════

1️⃣ src/main/resources/application.properties

   OBRIGATÓRIO:
   ├─ app.discord.token=${DISCORD_BOT_TOKEN}
   └─ app.discord.channel-id=${DISCORD_CHANNEL_ID}

   OPCIONAL:
   ├─ app.feeds.urls[0]=... (adicionar/remover feeds)
   └─ app.scheduler.fixed-delay=... (alterar intervalo)

2️⃣ Variáveis de Ambiente (RECOMENDADO)

   Windows PowerShell:
   ├─ [Environment]::SetEnvironmentVariable("DISCORD_BOT_TOKEN", "xxx", "User")
   └─ [Environment]::SetEnvironmentVariable("DISCORD_CHANNEL_ID", "yyy", "User")

   Linux/Mac Bash:
   ├─ export DISCORD_BOT_TOKEN=xxx
   └─ export DISCORD_CHANNEL_ID=yyy

3️⃣ Arquivo .env Local (ALTERNATIVA)

   Crie: src/main/resources/application-local.properties
   └─ app.discord.token=seu_token
   └─ app.discord.channel-id=seu_id

   Execute com: mvn spring-boot:run -Dspring-boot.run.arguments="--spring.profiles.active=local"

VARIÁVEIS DE AMBIENTE NECESSÁRIAS:
═══════════════════════════════════════════════════════════════════════════════

DISCORD_BOT_TOKEN
  ├─ Obtém em: https://discord.com/developers/applications
  ├─ Formato: MTA4MzcyNzQyMzc5NzYwNjA2NA.Gf_hg5.xxxxxxxxxxxxxxxxxxxx
  ├─ Nunca compartilhe!
  └─ Inicie com: [Environment]::SetEnvironmentVariable() ou export

DISCORD_CHANNEL_ID
  ├─ Obtém em: Developer Mode ON no Discord
  ├─ Botão direito no canal → Copy Channel ID
  ├─ Formato: 1234567890123456789 (número grande)
  └─ Configure em application.properties ou variável de ambiente
